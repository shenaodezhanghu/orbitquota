## OrbitQuota · 星轨额度

First public preview for Windows x64.

- Earth-centered, flat solar and lunar quota orbits.
- Real weekly / five-hour reset progress, clockwise motion, quota-based rays and moon phase.
- Local day/night shading facing the Sun.
- Quota / Usage pages, fixed daily output chart, automatic per-model API-equivalent estimates.
- Drag, monitor selection, tray, and reduced-motion preference.

### Run

Install **Microsoft .NET 10 Desktop Runtime (x64)**, extract **the entire ZIP**, then double-click `OrbitQuota.exe`. Keep its DLL and runtime JSON files together. Sign in to the official Codex CLI first; the tool reuses its existing account.

The app is an unsigned preview. USD amounts are estimates, not additional ChatGPT subscription charges. TTFT is not displayed because the local logs do not supply reliable timing. See the README for data coverage and offline fallback behavior.

`SHA256SUMS.txt` contains the archive checksum.
